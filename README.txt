SpringGenAi - AI Agent (Spring Boot + Spring AI + Gemini)

1. Set key (new key, not the old one):
   PowerShell:  $env:GEMINI_API_KEY="your_new_key"
   cmd:         set GEMINI_API_KEY=your_new_key
   Linux/Mac:   export GEMINI_API_KEY=your_new_key
2. Run:  mvn spring-boot:run   (or mvnw spring-boot:run if you have the .mvn folder)
3. Open: http://localhost:9999/
